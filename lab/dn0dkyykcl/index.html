Internal prototype

This page is for Checkmate Dynamics bench testing only.

New board?

Set it up from this device over Bluetooth. No computer needed: pick the network, type its password, name the motor.

Start Checkmate Link (bridge) to see your devices

The bridge runs on this PC and talks to the board on your network. In a terminal:

cd %USERPROFILE%\checkmatedynamics
py -I software\app\beta\run.py

This page finds it on 127.0.0.1 port 8790 and keeps looking. Use Chrome or Edge, and allow access to devices on this computer if the browser asks.

bridge port

Pair with the bridge

Enter the pairing code the bridge printed in its terminal. It changes every time the bridge starts.

Add a new board

Wi-Fi passwords go over Bluetooth only encrypted. With current board firmware (pairing v3), the arrows are a fresh random code and the board must prove it saw the same arrows before anything is sent.

Alarm

Boards on your network

        ESP-NOW

          ESP-NOW goes through the USB gateway on this PC. Only a board you own (paired over Bluetooth) accepts it, and every command is signed. Stop goes out first, ahead of everything: the board holds the motor, then the bridge switches the driver off with a signed command. The board also stops and switches off by itself 1 s after the radio goes quiet.
